created 51 built-in image-generation outputs; with the existing front candidate,
52 raw drawings are preserved. The 23 review sequences include eight one-frame
construction views, front breathe/listen key studies, independent left/right

## Reproduce review derivatives

Required: existing Python/Pillow and exact saved raw PNGs. No new dependency,
cutout service or image-generation API fallback was used.

```bash
python3 experiments/p02-embodiment/scripts/assemble_black_motion_studies.py \
  --raw RAW_DIRECTORY --out requests.json --include-left-inbetweens
python3 experiments/p02-embodiment/scripts/export_black_motion_review.py \
  --requests requests.json --raw RAW_DIRECTORY --out FRESH_OUTPUT_DIRECTORY
```

The output contains raw/ exact PNG copies, requests.json, result.json, index.html,
normal/quarter GIFs and strips. GIFs are scaled review derivatives, not source
frames. Timing is 24 Hz integer ticks with cumulative GIF centisecond rounding.
Eight facings are separate construction views, never a temporal walk track.

## Bounded Godot review

`godot/black_motion_review.gd` is an explicitly invoked review-only player, not a
production importer/fallback. It uses AnimatedSprite2D/SpriteFrames, 24 FPS,
integer duration weights, exact source hashes, frame order, completion,
frame_post_draw, visible pixel readback and unchanged source hashes.

The final Xvfb/llvmpipe run consumed all 52 drawings and traversed all 23 studies
once. Frame order and completion passed; maximum total-track timing error
0.008823 seconds against a declared 0.075-second tolerance after two warmup
render boundaries. Zero Godot ERROR lines. XIM/VSync and wrapper warnings retained.
This is E3 review-runtime evidence only, not visual/motion/contact acceptance.

Missing-manifest and altered source hash both returned exit 1 before any track
started, with exact failed results retained separately as expected negatives.

The first attempt failed GDScript inferred-Variant typing for `presented`; the
explicit bool correction and original failed result are retained. A preliminary
0.25s timing tolerance was tightened to 0.075s with documented warmup, not used as
the final gate.
