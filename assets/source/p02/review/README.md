# Phase 02 visual review derivatives

These PNGs are deterministic, selected review derivatives produced from the
exact native references. They are candidates only and require explicit
operator visual approval; they do not approve the four diagonal views or any
motion language. The complete frame corpus and atlases are uploaded by the
`phase02-embodiment` workflow as versioned artifacts rather than committed to
ordinary Git.

Files:

- `six_view_correspondence_sheet.png` — native turnaround plus identity source.
- `diagonal_candidates_sheet.png` — four directional candidates, unapproved.
- `proportion_silhouette_root_sheet.png` — source-space grid and root.
- `anatomy_palette_sheet.png` — palette roles and anatomy invariants.
- `pose_limits_shadow_sheet.png` — bounded pose/contact/shadow policy.
- `core_motion_sheet.png` — temporal core candidate.
- `idle_variants_sheet.png` — idle A/B/C candidate comparison.
- `review_manifest.json` — deterministic SHA-256 and size manifest.
