# MON_BODY_SOURCE_V1 — candidate canon

This directory is the small, operator-reviewable body-canon gate for Phase 02.
It is not an approval record. The native identity master and turnaround remain
the sources of truth; this candidate makes their precedence and construction
inputs explicit before any library-scale production.

## Authority precedence

1. Hard anatomy invariants override both images: two fingers plus one thumb on
   each hand, three toes on each foot, and no added anatomy.
2. `identity-approved.png` governs species identity, face language, palette
   family, silhouette character, edge treatment, shadow language, and presence.
3. `turnaround-approved.png` governs neutral front/back/profile/top/bottom
   correspondence and limb attachment.
4. This candidate model records explicit proportions, pivots, landmarks, and
   limits. Diagonals and motion remain candidates pending operator approval.

The images are preserved byte-for-byte and are referenced by SHA-256 in
`mon_body_source_v1.json`. The SVG is an editable path-layer candidate whose
source image reference is intentionally retained for side-by-side comparison;
it is not a replacement identity master.

## Known ambiguity requiring operator choice

The approved references do not define neutral diagonal construction, named
control points, or temporal keys. `front_left` is therefore a review candidate,
not an approved facing. Any conflict in silhouette, face, digit readability, or
proportion stops expansion and returns to the operator.
