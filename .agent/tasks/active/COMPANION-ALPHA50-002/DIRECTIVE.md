Current prior art reinforces this acceptance choice: explicit internal-state factorization is a viable autonomy direction, and long-term-memory evaluation increasingly distinguishes memory-driven action from passive recall. No new framework is adopted.

## Scope

### A — canonical organism V2

1. Supersede candidate `organism-state-v1` for canonical use while preserving it as historical candidate evidence.
2. Define V2 canonical organism state using bounded integer/fixed-point fields with explicit units/scales for every canonical physiology, drive, utility, confidence/stress, skill-stability and learned-value field.
3. No canonical organism/drive/goal-ranking/learned-value/skill truth may require floating-point serialization.
4. Arithmetic must be deterministic, overflow-bounded and independently testable.
5. Boundary adapters may use noncanonical floats only after explicit conversion and may not persist them as canonical truth.
6. Determine whether any potentially lived/non-test V1 organism store exists. If none exists, record that and initialize V2 cleanly. If one exists, do not destructively migrate it; stop that migration and return to Architect.

### B — organism dynamics, goals and consequences

1. Use explicit elapsed organism time rather than loop-count-as-time.
2. Implement bounded dynamics including satiation/recovery effects so the organism cannot monotonically decay into idle by construction.
3. Actions must produce observable consequences on relevant internal state.
4. Implement actual goal proposal/arbitration from drives, commitments, remembered opportunities and unfinished work.
5. Selection evidence must expose winning causal terms and inhibited alternatives.
6. Commitments must create/resume/complete/expire/revoke through production transitions.
7. User absence removes unavailable social actions but does not stop coherent autonomous activity.

### C — causal memory, correction, learning and development

For each acceptance case, run paired controls where all state is identical except the target evidence and prove a changed later production action or action parameter for the intended reason:

1. grounded user preference;
2. direct correction with historical supersession preserved;
3. unfinished commitment;
4. learned action outcome/skill value.

Additional requirements:

- learned outcomes and skill mastery must be consumed by production action selection;
- preference content must map through explicit typed semantics rather than a hard-coded universal action;
- retrieval must enforce temporal validity, supersession, scope/privacy and confidence;
- unresolved conflicting current evidence must abstain;
- development promotion must require defined competence/stability evidence, with a time-only negative;
- consolidation must operate on real typed records and produce auditable proposals for episode closure, contradiction/generalization, preference/routine, skill update, unfinished-goal carry-forward and curiosity/question generation where source evidence supports them;
- factual promotions must cite real evidence;
- synthetic dream/rehearsal material remains synthetic and a false-external-event promotion mutation must fail.

### D — production remembered-interaction chain

Implement and qualify the actual resident path. Direct calls from a qualification binary into organism helper methods cannot substitute for this proof.

Required chain:

1. authorized synthetic ordinary observation enters through the accepted ordinary producer/sensor-gateway boundary;
2. `companion-core` validates and appends canonical event evidence;
3. resident production organism logic updates internal state and typed memory from that event;
4. production selection emits a typed body-neutral intent with correlation/causation/provenance;
5. intent crosses the accepted bridge/IPC boundary to real Godot;
6. Godot resolves a legal frozen-pack presentation route and executes it;
7. observed execution result returns over the typed result boundary;
8. `companion-core` interprets result, records outcome evidence and updates relevant skill/learning state;
9. durable state/snapshot is written;
10. terminate `companion-core` and Godot;
11. restart the same individual and body;
12. later ordinary context activates remembered evidence;
13. paired control proves remembered evidence changes the later production action.

Run a separate Godot-loss case and prove canonical identity, organism state, memory and commitments survive unchanged.
