## Workstream B — persistent organism core

Implement canonical organism state in authoritative Rust `companion-core`, independent of Godot and language models.

Durable state must include at minimum:

- immutable identity/origin and organism epoch;
- organism time/lifecycle;
- developmental stage/capability gates;
- explicit internal variables sufficient to represent energy/rest pressure, stimulation/engagement, social need, curiosity, confidence/stress or equivalent grounded factors;
- derived drive state;
- active goals/priorities;
- commitments/prospective obligations;
- unfinished actions/plans;
- attention/context references;
- skill/mastery references;
- memory references;
- explicit degradation flags.

Implement the R01 life loop: ingest accepted evidence; advance physiology/time; recompute drive urgency; reassess goals/commitments; select/continue a context-valid action using inspectable utility/inhibition; emit a body-neutral intent or rest/no-op; ingest action result; update relevant state/skill evidence; append canonical event; continue during user absence with constrained opportunities rather than pausing existence.

No LLM/model may own canonical state, goals, drives, utility, or scheduling. Deterministic qualification must use retained seed + event/time traces. Commitments and unfinished goals resume after restart. Model-worker outage must not stop identity, physiology, basic arbitration, memory writing, or body-neutral behavior. Simulated/accelerated time must be isolated from lived history.

## Workstream C — typed life memory

Using the approved local SQLite authority model, implement typed memory owned by `companion-core`:

- append-only accepted event evidence;
- working-memory references where persistence is appropriate;
- episodic memory;
- semantic/belief memory;
- procedural/skill memory;
- relationship memory;
- preference memory;
- prospective memory/commitments.

Derived memory retains provenance and temporal scope. Corrections supersede rather than silently rewrite. Beliefs carry support/contradiction, confidence, valid-from/valid-until, and fact/hypothesis/question status. Retrieval respects participant, temporal scope, supersession, privacy class, confidence, and relevance and can abstain. Prospective memory transitions pending/completed/expired/revoked. Restart/export/restore preserve ordering and references.

Implement deterministic consolidation/dream processing that may close episodes, detect repetition/contradiction, propose generalizations/preferences/routines/skill updates/curiosities/unfinished goals, and reduce redundant retrieval strength. **Synthetic dream/rehearsal content may never become evidence that an external event occurred.**

## Workstream D — grounded learning and development

Do not update foundation-model weights online.

Implement:

- correction and demonstration records;
- skill progression equivalent to observed → attempted → corrected/practiced → competent/generalized;

Prove **memory-to-action causality**: at least one remembered preference, one prior correction, one unfinished commitment, and one learned action outcome measurably change later behavior relative to controlled baselines.

## Workstream E — Godot embodiment integration

Use existing `sensor-gateway`. Do not select a speech/vision model in this milestone.

## Workstream G — remembered interaction + shadow help

Implement the named cross-phase vertical slice:

1. clearly labeled synthetic ordinary interaction enters normal companion evidence path;
2. organism state changes and an explicit reason causes an action/goal;
3. Godot executes and reports the body-neutral action;
4. interaction promotes into appropriate typed memory with provenance;
5. complete runtime restarts;
6. same individual restores identity, organism state, relevant memory, goal/commitment, and learned state;
7. later context causes that memory to measurably change action selection;
8. independently, a synthetic safety candidate reaches `care-core` directly, is evaluated by explicit shadow policy, and creates/updates shadow incident state without depending on companion mood/memory/Godot/dialogue;
9. no external notification is delivered;
10. kill `companion-core` while the safety path runs and prove care intake still works;
11. kill `care-core` and prove ordinary companion life may continue while care coverage becomes explicitly degraded.

This is integration evidence, not care efficacy or production safety approval.
