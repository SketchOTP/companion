### B — Use the real production Godot body path

For this directive's causal trials, the Rust bridge is transport/validation only. It may not choose the presentation family, track or route used as acceptance evidence.

Real Godot 4.7.2 must receive each body-neutral intent through the normal presentation entry point and execute through:

`MonAnimationDirector -> MonTransitionResolver where applicable -> avatar/controller -> frozen R06 presentation clock/render path`

Godot must return the actual correlated result containing at minimum:

- intent ID;
- signed-range intent sequence;
- accepted/rejected state;
- concrete executed track/route identity;
- terminal presentation state;
- completion/cancellation reason;
- frozen pack identity;
- correlation/causation identifiers;
- observed render commitment where the executed action renders.

`companion-core` remains the only authority that interprets that result as organism outcome/learning.

This directive does not require the full 10,000-case transition acceptance campaign. It requires enough legal production-body execution to prove the causal comparisons below without a bridge or qualification-only bypass.

### C — Paired-control discipline

Each causal comparison must begin from the same retained baseline state or from independently restored byte/semantic-equivalent baseline stores.

Within a pair, all relevant non-target variables must be equal:

- identity/epoch;
- organism tick/time;
- physiology/drives;
- goals except the target when the target itself is a commitment;
- unrelated memories;
- skills/outcomes except the target learned outcome;
- user-present/context inputs;
- deterministic seed;
- Godot presentation start state;
- frozen pack/version.

The target difference must enter through an authorized production evidence/result path rather than direct test mutation, except that an isolated control store may deliberately omit the target evidence before execution.

Retain canonical pre-state and post-state digests plus a machine-readable field-difference report proving the target is the causal difference.

### D — Preference causal pair

Using real authenticated ordinary evidence, establish a typed remembered preference in the target branch.

Later provide identical authenticated context to target and control.

Pass only if:

- retrieval selects the current in-scope preference with provenance;
- production arbitration consumes it;
- target and control select different body action or materially different action parameters;
- the target action is executed through real Godot;
- raw evidence shows the remembered preference is the reason for the delta.

Do not hard-code all preferences to one fixed action. Use at least two representable action alternatives from the current body vocabulary.

### E — Correction causal pair

Start from a real prior preference/belief present in both branches.

Through authenticated ordinary evidence, correct only the target branch.

Pass only if:

- old memory remains as history and becomes superseded/non-current;
- new current memory references the correction/provenance;
- later identical context retrieves the corrected current value rather than the superseded value;
- target and stale-control branches choose differently;
- target executes the corrected-state-driven action through real Godot.

### F — Commitment causal pair

Create a bounded synthetic qualification commitment through the same resident companion authority path used to create canonical commitments. The harness may request the condition through authenticated synthetic ordinary evidence, but it may not write the commitment table/state directly.

Pass only if:

- target has one explicit pending commitment and control does not;
- all other selection state is equal;
- later identical context produces a different production decision because the pending commitment competes successfully;
- the selected target behavior executes through real Godot;
- commitment provenance and lifecycle state are auditable.

Do not claim this synthetic qualification commitment is a lived owner promise.

### G — Real Godot outcome causal pair

This is the strongest learning test.

Start target and control from equivalent state with no target learned outcome difference.

Target branch must execute a real Godot action and receive an actual observed result. The result must update companion-owned learned outcome and/or skill state.

Control branch must not receive that result/learning evidence.

Later provide identical context.

Pass only if:

- learned outcome/skill is read by production arbitration, not merely reported;
- the later target decision differs from control because of that learned result;
- target later behavior executes through real Godot;
- removing or tampering with the result evidence makes the independent verifier reject the causal claim.

### H — Full restart remembered-action proof

Choose at least one of the passing target causal cases above; preference or real-outcome learning is preferred.

After the learning/memory event and durable snapshot:

1. terminate `companion-core`;
2. terminate the real Godot body process/session used by the qualification;
3. preserve the authority stores only through their normal durable path;
4. restart the resident processes;
5. prove the same companion identity and organism epoch are restored;
6. prove the target memory/learning record and provenance survive;
7. establish the same Godot starting presentation state in target/control;
8. provide identical later authenticated context;
9. prove target and otherwise-identical control choose differently;
10. execute the target's remembered-state-driven action through real Godot;
11. retain the resulting observed execution result.

This is the primary acceptance event for the directive.

### I — Anti-confound and tamper negatives

The independent verifier must reject each of these:

- target memory removed while result still claims causal PASS;
- target/control contain an unrelated physiology or goal difference;
- superseded correction record is used as current truth;
- commitment is inserted directly by the harness instead of through companion authority;
- learned-result row/state is mutated directly rather than produced by observed body result;
- Rust bridge supplies a fabricated success without Godot execution;
- wrong intent ID/sequence/correlation;
- wrong frozen pack identity;
- post-restart identity/epoch mismatch;
- result says behavior differed but actual selected action/parameters are equal.
