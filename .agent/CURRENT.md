operator-approved visual references but does not yet have one approved,
machine-readable production embodiment canon or an approved motion language.

before those foundations and prohibited the intermediate operator checkpoint
needed to establish them.

- one procedural pose for each family and direction;
- direction used as temporal frame progression;

- tautological or self-reported counters used as transition/performance proof;
- bulk generated outputs committed before identity and motion approval.

This is an Architect-level gate-design failure plus an implementation failure.
Patching the generator, transferring the references, or obtaining the target
display in isolation would not resolve it.
